# nodejs-version-info (retired)

**This image is no longer updated.** The tool now lives in
[nvitaterna/nodejs-distroless](https://github.com/nvitaterna/nodejs-distroless)
under `tools/version-info/`, where the hourly version check runs it directly.

It listed the Node.js release lines that
[`nvitaterna/nodejs-distroless`](https://hub.docker.com/r/nvitaterna/nodejs-distroless)
builds images for.
