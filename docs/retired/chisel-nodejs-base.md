# chisel-nodejs-base (retired)

**This image is no longer updated.** The chisel base it provided is now built
inside [nvitaterna/nodejs-distroless](https://github.com/nvitaterna/nodejs-distroless)
(the `base` stage of its Dockerfile), so it no longer needs a separate image.

The last tag is `0.3.1` (Ubuntu 26.04 LTS). Use
[`nvitaterna/nodejs-distroless`](https://hub.docker.com/r/nvitaterna/nodejs-distroless)
for ready-made distroless Node.js images.
